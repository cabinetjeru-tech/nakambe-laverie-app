# 09_ARCHIVES — Archives

Versions remplacées et documents archivés. Rien n'y est supprimé : ces ressources restent dans l'historique mais ne sont jamais consultées pour répondre.

Pour archiver une ressource : déplacez le fichier **et** sa fiche ici en reprenant le même chemin que dans sa catégorie d'origine
(par exemple `09_ARCHIVES/01_PROGRAMMES_ET_CURRICULA/BURKINA_FASO/...`), et passez son statut à `ARCHIVE` ou `REMPLACÉ`.

Organisation à l'intérieur de ce dossier :

```
PAYS / NIVEAU / CLASSE / MATIÈRE / TYPE_DE_DOCUMENT / ANNÉE / VERSION / fichier
```

Types de document usuels ici : même organisation que la catégorie d'origine.

Mode d'emploi complet (fiche descriptive, statuts, versions) : [`../LISEZ-MOI.md`](../LISEZ-MOI.md).
